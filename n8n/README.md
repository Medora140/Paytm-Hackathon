# n8n Automation Workflows

This directory holds version-controlled JSON export files for n8n workflows:
- scrape-benchmarks.json: Scheduled weekly benchmark scraping job trigger.
- e-analyze-on-kb-update.json: Document re-analysis trigger upon red-flag KB additions.
- ocr-overflow-queue.json: Heavy/scanned PDF ingestion handoff.
- pipeline-health-alerts.json: System error monitoring and ops alerts.
